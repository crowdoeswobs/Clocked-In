# C'locked In

A small Windows 11 tray app for tracking work hours.

- Start, pause and stop the clock from the tray; the icon shows the state (green working, amber paused, red past your daily limit)
- Several jobs, each with its own hours, breaks and hourly rate
- Week (Mon–Sun) and month views with total time and pay
- Add breaks or forgotten work time afterwards
- Export to a spreadsheet (.xlsx), CSV, or a table you can paste into Notion
- Light, dark and glass themes; resizable panel
- Reminders, optional Do Not Disturb while working, start with Windows
- Shortcut: **Ctrl + Shift + Win + C**
